## Default Permission

Allows dialing, framing, and closing a peerline-over-Iroh P2P transport, and decoding/probing a ticket.

#### This default permission set includes the following:

- `allow-connect`
- `allow-send`
- `allow-close`
- `allow-inspect-ticket`
- `allow-probe-ticket`
